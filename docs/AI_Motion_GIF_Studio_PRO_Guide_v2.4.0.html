1. 시스템 아키텍처 & 핵심 엔진 개요

Zero-Layout-Shift 원칙: 고해상도 데스크탑부터 13~15인치 노트북 환경까지 3단 메인 레이아웃의 컨테이너 크기 및 버튼 배치를 100% 동결 유지하면서, 뷰포트 크기를 유연하게 맞추는 비침습적 반응형 파이프라인을 구축했습니다.

  • Layer 0 (Background): 순수 투명, 화이트/다크 스튜디오, 8종 그라데이션, 사전 다운스케일링된 사용자 업로드 이미지
  • Layer 1 (Dynamic Motion): 24 FPS 모션 루프, 바운스/위글/글리치 등 동적 프레임 버퍼 실시간 합성
  • Layer 2 (Foreground & Subtitle): 상업용 무료 폰트 10선 렌더러 및 마우스 드래그 조절형 3포인트 벡터 꼬리 말풍선

4. 안전 백업 및 프로덕션 배포 가이드

배포 전 주의사항: 형상 관리(Git)는 수동 승인 후 안전 커밋 및 태그 생성을 진행하며, 브라우저 빌드 캐시를 초기화한 후 배포 파이프라인을 실행합니다. GitHub Pages는 main 푸시 시 .github/workflows/deploy.yml이 npm run build 후 배포합니다. 앱 내 HUD 단계 수는 고정 10이 아니라 DIAG_STEPS.length를 따릅니다.
  1. 로컬 검증: npm run diagnose 후 npm run test:loop (캐시 삭제 · Vite --force 재기동 · Playwright Hard Reload)
  2. 프로덕션 빌드 검증: npm run build 실행 후 번들 생성 확인
  3. 스냅샷 안전 백업: git add . && git commit 후 v2.4.0 및 v2.4.0-stable-backup 태그
  4. 배포: git push origin main 및 태그 푸시 → GitHub Pages Actions
