# [UI SPEC] 독립형 AI 모션 GIF 스튜디오 PRO UI/UX 및 인터랙션 상세 명세서

관련 문서: `docs/MOTION_GIF_STUDIO_PRD.md`, `docs/MOTION_GIF_STUDIO_ARCHITECTURE.md`

본 명세는 `src/components/MotionGifStudio/ui/` 에 구현될 모달 UI만 다룬다. 본체 스튜디오 레이아웃, 이모티콘 분할기, 18단계 HUD DOM은 변경하지 않는다.

## 1. 3단 분할 모달 레이아웃 규격

모달은 본문 위 오버레이(`role="dialog"`, `aria-modal="true"`). 권장 크기: 본체 분할기와 유사하게 **최대 92vw × 86vh**, 내부는 노스크롤 셸 + 패널별 스크롤.

```
┌─────────────────────────────────────────────────────────────┐
│  독립형 AI 모션 GIF 스튜디오 PRO                    [닫기]   │
├────────────┬────────────────────────────┬───────────────────┤
│            │                            │                   │
│   좌측     │         중앙 뷰포트         │      우측         │
│   소스     │     60fps 실시간 프리뷰      │   프리셋 + 파라미터 │
│   인풋     │                            │                   │
│            │                            │                   │
├────────────┴────────────────────────────┴───────────────────┤
│  하단 상태바                          [🚀 GIF 다운로드]      │
└─────────────────────────────────────────────────────────────┘
```

### 1.1 좌측 — 소스 인풋 셀렉터

세그먼트 또는 탭 3종. 한 번에 하나의 소스가 활성(Active Source).

| 탭 | 내용 |
| --- | --- |
| 본체 연동 | `initialSource`가 있을 때만 활성. 메인 캔버스 타이포 스냅샷 썸네일 + [다시 받기] (Props가 갱신된 경우에만). 없으면 안내: 「본 프로그램에서 열면 캔버스가 여기에 들어옵니다.」 |
| 이모티콘 28종 | `initialSource.kind === 'emoticonCuts'` 일 때 5열 그리드. 칸 클릭 시 해당 컷만 모션 소스. 없으면 드롭/본체 연동 유도. |
| 파일 드롭 | 점선 드롭존. PNG/JPG. 클릭 시 `input[type=file]`. 거부 확장자는 하단 상태바에 경고. |

Self Text: 좌측 하단 접이식. 문구, 색, 크기만 스튜디오 내부 상태. 본체 레이어 카드와 동기화하지 않음.

### 1.2 중앙 — 60fps 실시간 뷰포트

- 정사각 프리뷰 스테이지. 소스가 없으면 플레이스홀더: 「왼쪽에서 이미지를 고르거나 파일을 놓으세요.」
- **줌 제어**: − / 배율 표시 / + / 맞춤. 기본 맞춤(contain). 팬은 줌 > 100% 일 때만.
- **배경 모드 토글** (순환 또는 3버튼):
  - `[🏁 체커보드]` 기본 — 투명 누끼 확인
  - `[⬛ 다크]` — 흰 스트로크·네온 대비
  - `[⬜ 라이트]` — 카카오 라이트 테마 대비
  배경은 CSS 플레이트. GIF 픽셀의 알파는 바꾸지 않는다.
- **재생/일시정지 타임라인**:
  - Play / Pause
  - 루프 스크러버 0~100% (`t / loopDuration`)
  - 현재 시각 `0.00s / N.NNs` 및 프리뷰 `60 FPS` 뱃지 (인코딩 FPS와 별도 표기)

프리뷰 캔버스는 Architecture의 Virtual Canvas 복사본만 표시한다.

### 1.3 우측 — 프리셋 카드 + 세부 슬라이더

**5대 모션 프리셋 카드** (단일 선택, 선택된 카드 `is-on`):

| ID | 라벨 | 한 줄 설명 |
| --- | --- | --- |
| `jellyBounce` | 젤리 바운스 | 탄성 상하 압축/도약 |
| `neonPulse` | 네온 브리딩 | 글로우 반경·투명도 순환 |
| `cuteWiggle` | 큐트 위글 | ±8° 틸트 + 바운스 |
| `rgbGlitch` | 시네마틱 글리치 | RGB 스플릿·디지털 스냅 |
| `softFloating` | 부드러운 부유 | 사인파 상하 루프 |

**세부 슬라이더 / 컨트롤**

| 컨트롤 | 범위 | 기본 | UI |
| --- | --- | --- | --- |
| 루프 시간 (속도) | 0.5s ~ 3.0s | 2.0s | range + 숫자 |
| 모션 강도 | 1% ~ 100% | 70% | range |
| 출력 FPS | 12 / 24 | 12 | 세그먼트 버튼 |
| 출력 해상도 | 360×360 / 500×500 / 원본 비율 | 360×360 | 세그먼트 또는 select |

변경은 프리뷰에 즉시 반영. 인코딩 중에는 컨트롤 disable.

### 1.4 하단 — 상태바 + 액션

- 왼쪽: 실시간 무결성 상태바 (소스 유효, 해상도, 추정 프레임 수, 추정 용량, 인코딩 단계).
- 오른쪽 주 버튼: **`[🚀 초고화질 무한루프 GIF 다운로드]`**
  - 소스 없음 / 인코딩 중: disabled
  - 클릭: 인코딩 시작 → 완료 시 파일 저장 (`motion-gif-360.gif` 등)

닫기: 헤더 X, ESC, 백드롭. 인코딩 중 닫기 시 confirm 또는 자동 abort 후 `onClose`.

## 2. 인터랙션 & 피드백 상태

### 2.1 로딩 스피너

| 상황 | 표시 |
| --- | --- |
| ingest (DataURL/Blob/File decode) | 중앙 뷰포트 오버레이 스피너 + 「소스 읽는 중…」 |
| ImageBitmap 생성 | 동일, 짧게 |
| 프리셋 첫 프레임 | 스피너 없이 첫 rAF 프레임을 바로 그림 |

소스 실패: 스피너 제거, 상태바 `error`, 뷰포트에 재시도 문구.

### 2.2 인코딩 진행률 (0% → 100%)

버튼 영역 또는 하단 바 위 프로그레스.

- `0%` 시작 (양자화 준비)
- `frameIndex / frameCount` 로 1%~99%
- `100%` Blob 생성 직후, 이어서 다운로드 트리거
- 선형 바 + `%` 숫자 + 「프레임 12 / 24」 보조 텍스트
- 취소: 진행 중 [취소] → abort, 바 리셋, 프리뷰 재생 재개

목표 체감: 360²·12fps·2s 구간에서 약 1초 내외. 지연 시 바가 멈추지 않고 마지막 프레임 비율을 유지.

### 2.3 유효성 경고

상태바 `warn` / `error`. 토스트는 짧게(파일 거부 등).

| 조건 | 메시지 예시 |
| --- | --- |
| 소스 없음 | 이미지를 먼저 고르세요. |
| 파일 형식 | PNG 또는 JPG만 올릴 수 있습니다. |
| 디코드 실패 | 이미지를 읽지 못했습니다. |
| 한 변이 너무 큼 (예: >4096) | 해상도가 너무 큽니다. 원본 비율 모드에서 축소됩니다. |
| 인코딩 abort | 내보내기를 취소했습니다. |
| GIF 투명 한계 | 반투명 안티앨리어싱은 1비트 투명으로 단순화될 수 있습니다. |

경고가 있어도 다운로드를 막을지는 심각도에 따름. 소스 없음·디코드 실패만 hard block.

### 2.4 파일 크기 실시간 미리보기

인코딩 전에는 **추정**: `width × height × frameCount × 0.3~0.6 bytes` 휴리스틱을 `약 240 KB` 형태로 상태바에 표시. 프리셋/FPS/해상도/루프 시간 변경 시 재계산.

인코딩 후에는 **실측** `blob.size`를 `완료 256 KB`로 교체. 카카오 업로드 한도 안내가 필요하면 상태바에 보조 문구만 넣고, 한도 숫자는 구현 시 정책 값으로 둔다.

### 2.5 상태 머신 (요약)

`idle` → `ingesting` → `previewing` → `encoding` → `done` → `previewing`  
어디서든 `isOpen===false` 이면 `teardown` (Architecture 4.1).

접근성: 진행률 `role="progressbar"` `aria-valuenow`. 주 버튼에 인코딩 중 레이블 변경 (`인코딩 중 42%`).
