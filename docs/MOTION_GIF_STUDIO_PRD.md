# [PRD] 독립형 AI 모션 GIF 스튜디오 PRO 기획 및 아키텍처 명세서

## 1. 프로젝트 개요 (Executive Summary)

- **목적**: 클라이언트(브라우저) 자원을 활용한 고품질 무한루프 모션 GIF 독립 생성 스튜디오 구축.
- **핵심 가치**:
  - 외부 서버 의존 0%, API 비용 0원의 브라우저 캔버스/gifenc 기반 초고속 렌더링(1초 내외).
  - 투명 배경(Alpha Channel) 무손실 보존 및 카카오 규격(360x360) 100% 준수.
  - 본 프로그램과의 자연스러운 데이터 연동 + 단독 실행(Standalone) 듀얼 인풋 아키텍처.

## 2. 격리 샌드박스 아키텍처 (Sandboxing Architecture)

- **독립 컴포넌트 격리**: `src/components/MotionGifStudio/` 독립 디렉토리 내에만 위치.
- **독립 가상 캔버스**: 본체 캔버스와 분리된 자체 Virtual Offscreen Canvas를 사용하여 본체 상태 오염 0% 보장.
- **클린 인터페이스 통신**:
  - `isOpen`: 스튜디오 모달 표시 여부
  - `onClose`: 스튜디오 종료 핸들러
  - `initialSource`: 본체에서 넘겨받는 이미지 데이터(Canvas, Blob, Base64 등 - 선택 사항)

## 3. 핵심 기능 요구사항 (Functional Requirements)

1. **듀얼 소스 인풋**:
   - 본 프로그램 연동: 메인 캔버스 타이포그래피 또는 이모티콘 28종 개별 컷 원클릭 수신.
   - 단독 실행 모드: 사용자 로컬 이미지(PNG/JPG) 드래그 앤 드롭 업로드, 스튜디오 내 자체 텍스트 입력.
2. **5대 시그니처 모션 프리셋**:
   - 젤리 바운스 (Jelly Bounce): 탄성 기반 상하 압축/도약 모션.
   - 네온 브리딩 (Neon Pulse): 글로우 반경 및 투명도 주기적 순환.
   - 큐트 위글 (Cute Wiggle): 좌우 틸트 회전(±8도) 및 바운스.
   - 시네마틱 글리치 (RGB Glitch): RGB 채널 스플릿 및 디지털 스냅.
   - 부드러운 부유 (Soft Floating): 부드러운 사인파 상하 부유 루프.
3. **프로페셔널 세부 파라미터 제어**:
   - 루프 시간(0.5s ~ 3.0s), 모션 강도(1% ~ 100%), FPS(12fps / 24fps).
   - 캔버스 규격: 카카오 이모티콘(360x360), 1:1 정사각(500x500), 원본 비율 유지.
4. **실시간 프리뷰 & 시각 검증**:
   - 60fps 무한루프 실시간 캔버스 프리뷰.
   - 배경 모드 토글: [🏁 체커보드] / [⬛ 다크] / [⬜ 라이트].

## 4. 단계별 구현 로드맵 (Milestones)

- **Phase 1**: 독립 디렉토리 구조 및 `gifenc` 코어 렌더러 모듈 셋업.
- **Phase 2**: 5대 이징 수학 공식 기반 프레임 생성기 및 실시간 뷰포트 구현.
- **Phase 3**: 본체 연동(수신) 핸들러 및 독립 드래그 앤 드롭 업로더 연결.
- **Phase 4**: 무결성 검증, 빌드 테스트 및 최종 릴리즈.
