# Calligraphy Studio 공식 가이드북

메인 편집창 · 시트 분할기 · 모션 GIF 스튜디오의 최신 사용법입니다. 화면 레이아웃은 사용자가 맞춘 상태를 기준으로 하며, 이 문서는 동작만 설명합니다.

---

## 1. 초정밀 픽셀 선택 추출기

모션 스튜디오에서 `[✨ 초정밀 픽셀 추출]`을 누르면 가로 최대 팝업이 열립니다. 좌·우 툴바는 128px로 1:1 대칭이고, 가운데 캔버스는 원본 비율을 유지한 채 남은 폭을 채웁니다(와이드/세로/정사각, `object-contain`). 고정 300% 줌이나 정사각 강제 크롭은 없습니다.

### 왼쪽 도구

- **브러시 / 지우개**: 클릭·드래그로 마스크를 칠하거나 지웁니다. 브러시 크기 1·2·4·8·16을 고릅니다.
- **매직 완드**: 비슷한 색 덩어리를 한 번에 고릅니다. 캐릭터와 배경 경계가 분명할 때 먼저 쓰고, 세부는 브러시로 다듬습니다.
- **50×50 정밀확대**: `[🔍 정밀확대]` 또는 돋보기 도구로 클릭한 지점 50×50 격자가 열립니다. 한 칸이 원본 1픽셀입니다. 격자에서 칠하면 메인 마스크와 바로 동기화됩니다.

### 오른쪽 히스토리

- **임시저장 / 불러오기**: 지금 마스크를 초안으로 남기거나 다시 불러옵니다.
- **Undo / Redo**: 한 획씩 되돌리거나 다시 적용합니다.
- **선택 반전**: 고른 영역과 나머지를 바꿉니다. 배경만 지운 뒤 반전해 캐릭터만 남길 때 씁니다.
- **영역 확장 / 축소**: 마스크 가장자리를 1픽셀씩 키우거나 줄입니다.
- **적용**: 마스크로 스프라이트를 잘라 스튜디오에 반영합니다. `[🔄 원본 복원]`으로 추출 전 이미지로 돌아갑니다.

---

## 2. 원클릭 완전 투명화 파이프라인

스타일러 본문을 모션 스튜디오로 넘길 때 화면에 보이는 체커보드·가이드 십자는 **내보내지 않습니다.**

1. 본체 그래픽은 `exportCleanCanvas`로 가이드/격자/플레이트를 끈 투명 PNG만 만듭니다.
2. 모션 스튜디오가 이미지를 받으면 `enforceTransparencyPurge`가 가짜 체커·다크 플레이트·시안 가이드 픽셀을 가장자리부터 지웁니다.
3. 이모티콘 컷도 같은 수신 정화를 탑니다. 미리보기 배경의 체커보드는 화면용이고, GIF/WebP 알파에는 들어가지 않습니다.

불투명 잔여물이 보이면 `[🪄 캐릭터 영역 자동 추출]` 또는 픽셀 추출 후 `[원본 복원]`으로 다시 시작하세요.

## 3. 감성 말풍선 / 자막 폰트 10선

자막 입력창 옆 셀렉터에서 고르면 미리보기와 GIF/WebP가 같은 웹폰트로 그려집니다. 기본은 **주아체**입니다.

| 폰트 | 이런 이모티콘에 |
|---|---|
| 주아체 | 귀여움 1순위. 일상·인사·하트 |
| 도현체 | 굵은 강조. 놀람·경고·한 줄 임팩트 |
| 쿠키런체 | 게임·캐릭터·통통 발랄 |
| 몬소리체 | 제목형 에너지. 외침·세일 |
| G마켓 산스 | 가독성. 안내·가격·설명 |
| 빙그레체 | 부드러운 브랜드·친근한 멘트 |
| 연성체 | 손글씨 온기. 감사·편지 |
| 봄바람체 | 경쾌한 손글씨. 봄·이벤트 |
| 배찌체 | 아기자기한 컷 대사 |
| 프리텐다드 | 군더더기 없는 완성형 고딕 |

폰트는 Google Fonts / 눈누 상업용 무료 파일을 씁니다. 자막 바가 열리면 10종을 `document.fonts.ready` 뒤 한 번에 미리 올려 돋움체 깜빡임을 막고, GIF/WebP 인코더도 같은 웹폰트를 기다린 뒤 합성합니다.

`[💬 꼬리 ON]`을 켜면 흰 말풍선과 꼬리가 한 벡터 패스로 그려집니다. 청록 점은 가리키는 끝(P3), 노란 두 점은 본체 부착점(P1·P2)입니다. 12px 안에서 잡고 드래그하면 방향이 바뀝니다. GIF/WebP에는 조절점 없이 말풍선만 들어갑니다.

## 4. 개발 및 셀프 검증 프로토콜

터미널에서 한 줄로 끝냅니다.

```bash
npm run verify
```

순서:

1. `npm run diagnose` — `tests/autoRepair.test.js`와 자가진단 HUD 항목을 돌립니다.
2. `npm run test:loop` — `node_modules/.vite` 등 빌드 캐시를 지우고 Vite `--force`로 재기동합니다.
3. Windows 기본 브라우저는 **한 창만** 재사용합니다. 이미 열린 스튜디오 탭이 있으면 새 창을 띄우지 않습니다.
4. Playwright가 캐시 무시 헤더와 Hard Reload로 `public/test-result.png`를 갱신합니다.
5. 끝나면 헤드셋(기본 출력)으로 **1차 띠리릭**이 나고, 5초 동안 입력이 없으면 **2차 리마인드**가 납니다.

승인: `[1: 승인 및 종료]` / `[2: 추가 수정 필요]`
